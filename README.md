# Resume Builder Pro

A full-stack web application for creating professional, ATS-friendly resumes with live preview, PDF download, and database storage.

## Features

- Create and edit resume details
- Dynamic Education, Experience, Projects and Certifications sections
- Real-time resume preview
- A4 resume layout
- Download resume as PDF
- Save resumes to MySQL database
- Load saved resumes
- Open and edit existing resumes
- Update saved resumes
- Delete saved resumes

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript
- html2pdf.js

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST API

### Database
- MySQL
